# Syed Jawwad Raza's portfolio

Live at **https://syed-jawwad-raza.github.io/**

A one-page portfolio designed like engraved security paper. The rosette at the top is a guilloche pattern drawn on a canvas from a random seed, so every visit gets a different plate. The contact form is a cheque that opens an email draft.

Built with plain HTML, CSS and JavaScript.

## Updating it

All career details live in [`content.js`](content.js). Edit that file, here on GitHub with the pencil icon or locally, and GitHub Pages republishes the site in about a minute. Then open https://syed-jawwad-raza.github.io/?check to confirm the page still matches the data.

[`og.png`](og.png) is the image shown in link previews. Replace it with a 1200 × 630 screenshot if the name or headline changes.
